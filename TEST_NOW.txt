🔧 HOW IT WORKS:

1. Client makes API call (e.g., /api/screenshot)
2. FastAPI route handler receives request
3. Instead of async Playwright:
   - Use: await run_in_threadpool(browser_manager.take_screenshot)
4. Sync Playwright runs in a worker thread
5. Result returned to client
6. Server stays responsive (never blocks)

Result: Best of both worlds!
├─ FastAPI async responsiveness
├─ Simple synchronous Playwright code
└─ No subprocess issues on Windows
