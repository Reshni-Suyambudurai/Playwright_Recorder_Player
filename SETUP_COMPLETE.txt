⚙️ CUSTOMIZATION OPTIONS:

Change Viewport:
  Edit: app/services/launchWeb.py (line ~20)
  Change: self.viewport = {"width": 1920, "height": 1080}

Change Port (8000 → 8080):
  Add: --port 8080
  Command: python -m uvicorn app.main:app --reload --port 8080
  Access: http://localhost:8080

Allow Remote Access:
  Command: python -m uvicorn app.main:app --reload --host 0.0.0.0
  Access from other PC: http://<your-ip>:8000

🐛 COMMON ISSUES & SOLUTIONS:

Problem: "Port already in use"
Solution: python -m uvicorn app.main:app --reload --port 8080

Problem: "Module not found: fastapi"
Solution: pip install -r requirements.txt

Problem: "Playwright not installed"
Solution: playwright install

Problem: "Can't see screenshots"
Solution: mkdir app/screenshots

Problem: "Server won't start"
Solution: Check Python version (python --version), need 3.7+

🎓 KEY CONCEPTS:

Headless:     Browser without GUI window (faster, automated)
Viewport:     Fixed screen size (1280x720) for consistency
Selector:     CSS path to find elements (e.g., "button.submit")
XPath:        XML path to find elements (e.g., "/html/body/button")
Coordinates:  Pixel position (X, Y) on the screen
elementFromPoint: JavaScript function to find element at X,Y
